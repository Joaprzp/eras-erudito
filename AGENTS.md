### Convex

<!-- convex-ai-start -->

This project uses [Convex](https://convex.dev) as its backend.

When working on Convex code, **always read
`convex/_generated/ai/guidelines.md` first** for important guidelines on
how to correctly use Convex APIs and patterns. The file contains rules that
override what you may have learned about Convex from training data.

Convex agent skills for common tasks can be installed by running
`npx convex ai-files install`.

<!-- convex-ai-end -->

The block above is generated by `convex ai-files`; leave its contents to the installer. Three repo rules apply on top of it:

- Run it as `bunx convex ai-files install`. This repo uses Bun exclusively, whatever the generated text says.
- The installer copies that same block into `CLAUDE.md`. Delete it from there — instructions live in this file, and `CLAUDE.md` stays a pointer to it.
- The installer writes two identical skill trees, `.agents/skills/` and `.claude/skills/`. Skills are per-tool configuration, not documentation: keep only the directory for a tool actually in use, and prune the skills that don't apply to this project. Today that means `.claude/skills/` with eight Convex skills; `convex-auth` is excluded on purpose because it wires user authentication, which ADR-0003 rules out.
